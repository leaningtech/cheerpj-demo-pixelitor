Pixelitor Browser Demo Java via CheerpJ

A full-featured Java image editor, running unchanged inside the browser via CheerpJ.

How to use

  1. A sample image is already open. Check the Layers panel on the right of the editor.
  2. Pick the Brush or another tool from the left toolbar and draw on the image.
  3. Open the Filter menu to apply effects, then use Edit → Undo to step back.

Tip: Ctrl+Z undoes the last step. Use the Zoom tool to inspect details.

Open your own image

  1. Click the arrow icon in the top right corner of the Pixelitor window's title bar, then choose an image from your computer.
  2. Go to File → Open...
  3. Look in the /uploads folder, select your image and click Open.
