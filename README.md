# CheerpJ Demo: Pixelitor

This demo runs [Pixelitor](https://github.com/lbalazscs/Pixelitor), a full-featured Java image editor, unchanged in the browser using CheerpJ. A sample image is already open, so you can start with the brush, layers, filters and blend modes right away.

To edit your own image, click the arrow icon in the Pixelitor title bar and choose a file from your computer. Then use **File → Open...** and look in the `/uploads` folder.

## Run Locally

```
git clone https://github.com/leaningtech/cheerpj-demo-pixelitor.git
cd cheerpj-demo-pixelitor
npx http-server
```
